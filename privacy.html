🔒 Politique de confidentialité

Vinted Tracker — Application personnelle de suivi d'emails

Dernière mise à jour : 1er septembre 2024

Résumé : Vinted Tracker est une application à usage strictement personnel. Elle accède à vos emails Gmail en lecture seule pour détecter les notifications Vinted. Aucune donnée n'est partagée avec des tiers. Toutes les informations restent sur votre machine locale.

1. Présentation de l'application

Vinted Tracker est une application web développée pour un usage privé et personnel. Elle s'exécute localement sur l'ordinateur de son utilisateur et permet de surveiller automatiquement les emails provenant de la plateforme Vinted (marketplace de revente d'articles d'occasion). L'application n'est pas commercialisée et n'est pas accessible au public.

2. Données collectées

L'application accède aux données suivantes via l'API Gmail officielle de Google, avec l'autorisation explicite de l'utilisateur et en mode lecture seule :

  • Adresse email : L'adresse du compte Gmail connecté, utilisée pour identifier le compte.
  • Emails Vinted uniquement : Le contenu des emails reçus depuis les expéditeurs officiels Vinted (no-reply@vinted.fr, no-reply@vinted.com, noreply@vinted.fr, no-reply@vinted.be, no-reply@vinted.de, no-reply@vinted.es, no-reply@vinted.it, no-reply@vinted.nl, support@vinted.fr).
  • Métadonnées des emails : Sujet, date de réception et expéditeur des emails Vinted.

L'application n'accède jamais aux emails d'autres expéditeurs. Elle ne lit pas, ne modifie pas, ne supprime pas, et n'envoie pas d'emails.

3. Données non collectées

L'application ne collecte pas les données suivantes :

  • Emails provenant d'expéditeurs autres que Vinted
  • Contacts Gmail
  • Pièces jointes
  • Données de navigation ou de localisation
  • Informations personnelles au-delà de celles présentes dans les emails Vinted
  • Données de paiement ou financières autres que celles mentionnées dans les emails Vinted

4. Utilisation des données

Les données accessibles via l'API Gmail sont utilisées exclusivement pour :

  • Identifier et classer les événements Vinted (vente, achat, question, favori, paiement, etc.)
  • Afficher l'historique des transactions dans le tableau de bord personnel
  • Calculer des statistiques de performance des ventes (chiffre d'affaires, bénéfice)
  • Afficher les annonces actives et les messages reçus d'acheteurs

5. Stockage des données

Toutes les données sont stockées exclusivement dans une base de données SQLite locale sur l'ordinateur de l'utilisateur (fichier data/vinted_tracker.db). Aucune donnée n'est transmise vers un serveur externe, un service cloud ou un tiers quelconque.

Les tokens d'authentification OAuth Google sont stockés localement dans le répertoire data/tokens/, sécurisés par les permissions du système de fichiers local. Ces fichiers ne sont jamais inclus dans des sauvegardes partagées ou des dépôts de code.

6. Partage des données

Aucune donnée n'est partagée avec des tiers. L'application ne dispose d'aucune connexion réseau sortante autre que l'API Gmail de Google, utilisée pour lire les emails de l'utilisateur avec son consentement explicite. Il n'y a pas de télémétrie, d'analytics, ou de service tiers intégré.

7. Authentification et sécurité

L'accès à Gmail est réalisé via le protocole OAuth 2.0 de Google, qui est le standard de sécurité officiel pour l'accès délégué aux services Google. L'utilisateur autorise explicitement l'application lors de la première connexion, et peut révoquer cet accès à tout moment depuis son compte Google (myaccount.google.com/permissions).

Le scope utilisé est https://www.googleapis.com/auth/gmail.readonly (lecture seule), ce qui signifie que l'application ne peut pas envoyer d'emails, modifier des messages ou accéder à d'autres services Google.

8. Conservation des données

Les données sont conservées aussi longtemps que l'utilisateur le souhaite. Elles peuvent être supprimées à tout moment en effaçant la base de données locale (data/vinted_tracker.db) ou en supprimant l'application de l'ordinateur.

9. Droits de l'utilisateur

En tant qu'utilisateur de cette application, vous avez le droit de :

  • Accéder à toutes les données stockées (base de données SQLite locale)
  • Modifier ou corriger toute information via le tableau de bord
  • Supprimer vos données à tout moment
  • Révoquer l'accès Gmail depuis votre compte Google à tout moment
  • Désinstaller l'application et supprimer toutes les données associées

10. Mineurs

Cette application est destinée à un usage adulte personnel. Elle n'est pas conçue pour être utilisée par des mineurs et ne collecte pas de données relatives à des mineurs.

11. Modifications de cette politique

Cette politique de confidentialité peut être mise à jour occasionnellement. En tant qu'application à usage strictement personnel, ces modifications n'affectent que l'utilisateur unique de l'application.
