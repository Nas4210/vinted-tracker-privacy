# Vinted Tracker

Vinted Tracker is a personal application that monitors Gmail inboxes to automatically detect Vinted marketplace emails (sales, listings, offers) and displays them in a unified dashboard.

## Features
- Automatic Gmail monitoring for Vinted emails
- Sales tracking and profit calculation
- Multi-account support
- Push notifications via ntfy.sh

## Usage
This application is for personal use only. It connects to Gmail via Google OAuth2 (read-only access) to read Vinted notification emails.
